2. 8 大領域詳細能力拆解與技術方案

1. 面積與法規計算 (area-calc-math) P1
將建築平面空間或牆心外框自動細切為矩形/三角形面積區塊，並自動產生長度、寬度、周長之計算字串與總和。
  • 主要功能：自動切面積、產生算式文字、計算式即時求值與求和驗證。
  • 適用階段：建照掛件、變更設計、容積/樓地板面積檢討。
2. 文公尺吉凶尺寸 (feng-shui-dimension) P1
針對大門、房門、開窗、神明桌、玄關等關鍵尺寸，依文公尺 42.854cm / 丁蘭尺進行吉凶八字判定與標註註記。
  • 主要功能：單一/批次尺寸查詢、下標/後綴標註（例：900 [寶庫-吉]）、一鍵清除。
  • 適用階段：豪宅客變、室內設計、門窗表尺寸確認。
3. 幾何接合治理 (geometry-join-governance) P1
解決 Revit 建模常見的柱樑版牆幾何重疊干涉、剖面線條雜亂、混凝土算量重複計算等問題。
  • 主要功能：全區/選取範圍批次 Join、柱樑版主從切割順序快速切換（Switch Join）。
  • 適用階段：結構建模完成、數量估算、剖立面施工圖產出前。
4. 圖冊圖紙治理 (sheet-batch-governance) P2
自動化管理施工圖冊目錄、圖號、圖名、版次與總張數統計。
  • 主要功能：從 Excel 匯入圖冊清單建立 Sheets、自動計算「第 X 張/共 Y 張」、視圖命名批次化。
  • 適用階段：細部設計出圖、建照/發包圖冊整理。
5. 智慧標籤與整列 (smart-tagging-alignment) P2
大幅縮短人工貼門窗 Tag、梁柱 Tag 及拉引線的時間，並避免文字重疊。
  • 主要功能：全自動按規則放 Tag、引線長度統一、引線端點改箭頭、文字水平整列。
  • 適用階段：平面施工圖、結構平面圖、大樣圖標註美化。
6. 車位編號劃設 (parking-space-renumber) P2
地下室車位常因動線複雜人工編號耗時且容易重複，透過動線導引自動編號。
  • 主要功能：沿手繪模型線/曲線自動按順序編號、依樓層前綴、大/小/無障礙車位分類統計。
  • 適用階段：地下室規劃、建照法規車位檢討、銷售圖面編號。
7. 水保坵塊與整地 (site-earthwork-grade) P3
針對山坡地基地自動切割坵塊網格並計算平均坡度與土方高程。
  • 主要功能：依網格採樣高程產出坵塊圖、測量點/基準點放樣座標自動標定、道路標線放樣。
  • 適用階段：山坡地水土保持計畫、整地土方計算、基地放樣。
8. 傳統屋頂瓦作 (traditional-roof-generator) P3
解決 Revit 預設屋頂工具難以建立圓筒瓦、溝頭滴水、人字垂脊等複雜傳統裝飾的問題。
  • 主要功能：沿屋頂曲面/斜面自動佈設瓦壟、滴水瓦、垂脊收邊元件與椽木結構。
  • 適用階段：古蹟修復、仿古建築、宗教寺廟建築設計。

3. Dynamo 轉譯為 Agent 技能的四部曲流程

  1. 節點解析 (Node Extraction)： 解析 .dyn 內 JSON 結構，提取關鍵 Python Script 演算法與 Revit API 呼叫方法。
  2. MCP 工具對齊 (Tool Alignment)： 將核心邏輯對接既有 RevitMCP Socket 指令（如 create_dimension, query_elements, update_parameters 等），或擴充專屬 MCP Command。
  3. 定義技能規範 (Skill Specification)： 在 .agents/skills/<skill-name>/SKILL.md 建立標準自然語言觸發詞、操作工作流與參數規則。
  4. 實機驗證 (Revit Verification)： 透過 Node.js 腳本在 Revit 實際專案中測試並確保執行效率與穩定性。
