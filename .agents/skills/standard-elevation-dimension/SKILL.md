# 標準立面與剖面階梯標註與軸線整列系統 (Standard Elevation Dimension)

> 📌 **分支狀態**：`feature/elevation-dimension-refactor` (獨立研發與測試沙盒)  
> 🎯 **核心宗旨**：徹底擺脫舊有被動抓取氣泡位置的缺陷，建立以**「實體 2D 外輪廓（Step 0）」**為主動基準、**「5 個等距階梯（Step 5 藍線齊頭）」**為邊界的立面與剖面標註標準體系。

---

## 🏛️ 一、幾何階梯放樣層級矩陣 (5-Step Module Architecture)

以視圖比例為基準，計算單一階距 $\text{StepSize} = 6.5\text{ mm} \times \text{view.Scale}$（$1:100$ 出圖比例下為 $650\text{ mm}$）：

| 階梯層級 | 距實體紅線距離 (@1:100) | 幾何角色與出圖元素 | 說明與標準型式 |
| :--- | :--- | :--- | :--- |
| **Step 5** | **$+3,250\text{ mm}$** | 🔵 **藍線齊頭基準線 (Datum Bubble Alignment)** | **所有軸線氣泡圓圈下緣 / 樓層標示圈 100% 齊平此線** |
| **Step 4** | **$+2,600\text{ mm}$** | 📏 **Tier 1 建築總跨度 / 建築總高度尺寸線** | 頂部全跨度總尺寸 / 側邊建築總高度（GL～TRFL） |
| **Step 3** | **$+1,950\text{ mm}$** | 📏 **Tier 2 連續柱間距 / 連續各層樓高尺寸線** | 連續柱心分段串接 / 連續各樓層高分段串接 |
| **Step 2** | **$+1,300\text{ mm}$** | ⬜ 尺寸線與建築外皮留白緩衝階梯 | 保持圖面通透，避免尺寸文字與實體交錯 |
| **Step 1** | **$+  650\text{ mm}$** | ⬜ 建築外皮第一道留白緩衝階梯 | 建築實體外框呼吸空間 |
| **Step 0** | **$0.0\text{ mm}$** | 🔴 **實體外輪廓包絡線 (Step 0 Envelope)** | **左右外牆實體外皮 / GL 地盤線 / 屋突最高頂面** |

## 🔍 二、實體外輪廓包絡偵測規範 (Step 0 邊界判定)

### 1. 立面圖 (Elevation View)
* **左側 / 右側外緣 (Left / Right)**：
  * 查詢視圖中所有外牆（包含 `OST_Walls` 與堆疊牆 `OST_StackedWalls`），計算其幾何表面投影極限值。
  * 包含外牆完成面（如烤漆鋼板、石材、面磚外皮），嚴禁使用結構柱心代替外牆皮。
* **頂部外緣 (Top)**：
  * 讀取最高實體頂部（女兒牆實體頂面 / 屋突最高頂面）。
* **底部外緣 (Bottom)**：
  * **立面圖嚴格以「GL 地盤線（$Z = 0.0\text{ mm}$）」為底層基準**，排除地下結構。

### 2. 剖面圖 (Section View)
* **左側 / 右側外緣 (Left / Right)**：同立面圖實體外牆面。
* **頂部外緣 (Top)**：最高實體女兒牆 / 屋突頂面。
* **底部外緣 (Bottom - 核心差異)**：
  * **剖面圖必須納入地下層，以「最底層筏基板（FB / FT）結構體底面」為底層基準紅線**。

---

## 📐 三、軸線 (Grids) 與樓層線 (Levels) 主動齊頭整列 (Active Alignment)

1. **垂直軸線 (Grids) 整列**：
   * 讀取該視圖內可見軸線。
   * 將軸線頂端 2D Datum Extent 主動延伸並 **精確鎖定於「頂部藍線（Step 5）」**。
   * 頂端氣泡圓圈開啟，底部關閉。
2. **水平樓層線 (Levels) 整列**：
   * 讀取該視圖內可見樓層線。
   * 將樓層線左端 2D Datum Extent 主動延伸並 **精確鎖定於「左側藍線（Step 5）」**。
   * 左端樓層標高圓圈開啟，右端關閉。

---

## 📏 四、雙向雙層標準標註規格與向量控制

### 1. 頂部柱心雙層標註 (Grids D $\leftrightarrow$ A)
* **標註型式**：`TABC-DIM_*/ S 2.5-柱心-上右`（**`TABC-空心點 1.5mm` 空心圓圈 + 黑色線條**）。
* **位置放樣**：
  * Tier 1 總跨度：**Step 4（$+2,600\text{ mm}$）**
  * Tier 2 連續柱心：**Step 3（$+1,950\text{ mm}$）**
* **向量方向**：**由右至左（東向西，A $\to$ D）建立**，使固定 5.0mm 短輔助線 **100% 朝下 $\downarrow$ 指向建物**。

### 2. 左側樓層高程雙層標註 (Levels GL $\to$ TRFL)
* **標註型式**：`TABC-DIM_*/ S 2.5-柱心-下右`（**`TABC-空心點 1.5mm` 空心圓圈 + 黑色線條**）。
* **位置放樣**：
  * Tier 1 總建高：**Step 4（$-2,600\text{ mm}$）**
  * Tier 2 連續層高：**Step 3（$-1,950\text{ mm}$）**（以 GL 為起點，連續標註至 TRFL）。
* **向量方向**：**由頂至底（TRFL $\to$ GL）建立**，使固定 5.0mm 短輔助線 **100% 朝右 $\rightarrow$ 指向建物**。

## 🔄 五、分支驗證與合併機制 (Safeguard Workflow)

1. **分支驗證 (In-Branch Testing)**：
   * 在 `feature/elevation-dimension-refactor` 分支中進行程式編譯、指令開發與實測。
   * 驗證視圖順序：**北向立面 $\to$ 東向立面 $\to$ 西向立面 $\to$ 南向立面 $\to$ 剖面圖**。
2. **簽核與合併 (Merge to Mainline)**：
   * 獲得使用者逐一確認「正確」後，才將分支變更與更新後的技能合併回主線 `main`。
3. **退場機制 (Rollback Safeguard)**：
   * 若測試結果不符預期，直接切換回 `main` 分支即可瞬間還原至穩定狀態，無任何程式碼污染風險。
