> **狀態：v2.1-Production (數據驅動穩健黃金版)**

## 📌 1. 技能背景與核心出圖規範

在台灣建築執照申請與都市計畫檢討圖冊中，「都市計畫土地使用分區管制要點」是建照審查必備的法規圖例（置於圖紙 `A102 - 法規檢討(一)-土地使用管制規定`）。
本技能將公部門「土地使用管制要點 PDF」透過高精度結構化解析，自動套入 Revit 圖例（Legend）視圖，產出符合事務所出圖標準的**固定公版雙欄流式法規檢討大表**。

## 🧮 3. 數據驅動排版數學模型與物理常數 (Deterministic Math Engine)

在 Revit 的絕對笛卡兒座標系中，**絕不可使用人工寫死的固定列高**。必須將文字離散化為行數（Lines），並以嚴格的物理常數推導座標：

```
Y_top (段落頂部基準線)
 │
 ├─── Top Padding (固定留白 3.0 mm，確保第一行不貼頂線)
 │
 ├─── Line 1 (字高 3.0mm, 行距 5.80mm)
 ├─── Line 2
 ├─── ...
 ├─── Line N (最後一行文字)
 │
 ├─── Bottom Padding (固定留白 3.5 ~ 4.0 mm，確保最後一行不貼底線)
 │
Y_divider = Y_top - (N_lines × 5.80 mm + 6.5 ~ 7.0 mm)   <── 橫線永遠嚴格位於文字下方！
 │
 └─── Next Paragraph Y_top (= Y_divider)                 <── 下一段從線下方開始，重疊率為 0！
```

### 3.1 黃金物理常數表

| 物理常數 | 數值 | 物理意義與防禦目的 |
| :--- | :---: | :--- |
| **基準行高（$\text{LINE\_PITCH}$）** | **`5.80 mm`** | Revit `3 mm 微軟正黑體` 在單一 TextNote 內的多行天然行高。 |
| **折行權重極限（$\text{WRAP\_MAX\_WEIGHT}$）** | **`48.5`** | **【黃金防禦常數】** 有效欄寬 $214\text{ mm}$ 下每行 48 字，保留 3~4 字安全緩衝，**100% 杜絕 Revit 避頭尾二次強制折行**。 |
| **單段總高推導公式** | **$H = N_{\text{lines}} \times 5.80 + 6.50\text{ mm}$** | 包含頂部留白 $3.0\text{ mm}$ 與底部留白 $3.5\text{ mm}$。 |
| **子表格表頭列高** | **`9.0 mm`** | 文字垂直置中於 $-3.0\text{ mm}$，上下留白 $3.0\text{ mm}$。 |
| **子表格資料列高** | **`8.0 mm`** | 單行資料列高 $8.0\text{ mm}$，雙行資料列高 $13.6\text{ mm}$，文字上下留白 $2.5\text{ mm}$，**字絕不貼線**。 |

## 📑 4. 原子化分項拆分與跨欄滿版流式架構 (Atomic Sub-clause Splitting)

為了徹底消滅「左下空一大欄未被利用」或「句子被硬生生腰斬」的現象，排版引擎採用**分項原子化前瞻探測演算法**：

```
                    ┌─────────────────────────┐
                    │ 準備排入某條文分項 (三) │
                    └────────────┬────────────┘
                                 │
                   計算：左欄剩餘空間是否足夠？
               (Y_current - H_clause >= Y_bottom_limit ?)
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
             【足夠 (YES)】                  【不足 (NO)】
                 │                               │
       放入左欄，畫分割線               ★ 嚴禁腰斬此分項！
       繼續處理下一分項                 ★ 左欄封口（留白約 15~30mm）
                                         ★ 攜帶分項 (三) 與後續內容
                                            另起右欄頂部！
                                         ★ 條號自動標記為「十三、(續)」
```

### 4.1 拆分三大核心準則
1. **分項原子性（Sub-clause Atomicity）**：最小拆分單位為「分項 `（一）`、`（二）`」。若當前欄位塞不下整個分項，**整項移至下一欄，寧可下方留白，絕不可將一個分項拆成兩半**。
2. **孤行標題防禦（Orphan Header Prevention）**：若欄位剩餘空間連 `[條文前言 + 分項（一）]` 都塞不下，**條文前言不得單獨留在欄底，整條移至下一欄開頭**。
3. **子表格不可跨欄撕裂**：表格 1（強度表）、表格 2（公設表）、表格 3（停車表）為超大原子塊，必須完整收納於同一欄內。

## 🚫 5. 歷史入坑點、迷幻現象與 10 大反模式深度防禦 (Pitfalls & Hallucinations)

在歷次除錯與實證過程中，總結出以下 10 大致命痛點與迷幻陷阱，後續開發與維護**絕對嚴禁再犯**：

| 序號 | 採坑現象（錯誤表徵） | 底層根本成因（迷幻點） | 唯一正確防禦規格 |
| :---: | :--- | :--- | :--- |
| **1** | **文字段落被橫線橫切（切字）** | 折行字寬設為 `50.5`，超過 Revit $214\text{ mm}$ 容納極限 $50.0$ 字，Revit 自動二次折行使實際行數多出 1 行，橫線位置落後 $5.8\text{ mm}$。 | **折行權重嚴格鎖定 `48.5`（黃金常數）**，保留 3~4 字安全緩衝，計算行數與實體行數 100% 等價。 |
| **2** | **段落文字疊羅漢（重疊）** | 下一段文字起點（Top Anchor）是從上一段錯誤估算的行高向下推算，兩段文字在空間座標上相交。 | **確定性幾何步進公式**：$Y_{\text{divider}} = Y_{\text{top}} - (N \times 5.80 + 6.50)$，下一段起點從 $Y_{\text{divider}}$ 起算，重疊率為 0。 |
| **3** | **左欄底端留下大片空白（空大欄）** | 條文採用「整條不拆」的粗粒度判斷，長條文（如十三條）因塞不下整條而被推到右欄，導致左欄留白 150mm。 | **原子化分項拆分**：在 `（一）`、`（二）` 邊界精確切分，前段填滿左欄，後段接續右欄掛 `(續)`。 |
| **4** | **分項間距過大（拉開 9.8mm）** | 將每個 `（一）`、`（二）` 各自做成獨立 TextNote 並疊加 `+4.0mm` 邊距，行距從 $5.8\text{ mm}$ 放大到 $9.8\text{ mm}$。 | **同欄同條合併 TextNote**（以 `\n` 連接）或將分項間隔設為純 $5.8\text{ mm}$ 步進，維持原生緊湊行距。 |
| **5** | **表格文字與格線緊貼（無呼吸空間）** | 表身列高僅給予 $7.0\text{ mm}$，扣除 3mm 字高後上下僅剩 $2.0\text{ mm}$，視覺貼線。 | **表格列高模矩化**：表頭 $9.0\text{ mm}$、資料列 $8.0\text{ mm}$，文字上下留白 $2.5\text{ mm}$。 |
| **6** | **法規公設市場代碼縮寫（漏字）** | 自行使用波浪號縮寫代碼（如 `潭-市1～市6`）或遺漏前綴（`豐交-`）。 | **100% Verbatim**：完整列出 `市場用地(豐交-市3、豐交-市5-1、豐交-市5-2)` 與 `市場用地(潭-市1、潭-市2、潭-市3、潭-市4、潭-市5、潭-市6)`。 |
| **7** | **停車條文第（二）1 款大段漏字** | 誤以為有停車表即可縮減條文，刪減了 200+ 字的法定折算文字。 | **法規最高標準**：保留完整 200+ 字說明，並緊接 14mm 雙層模矩化停車表。 |
| **8** | **表頭 4mm 文字被下方橫線切過** | 欄名列高維持 $0.8$（$7.5\text{ mm}$），低於 4mm 字體含上下 Padding 的安全空間。 | **欄名列高全面調升至 $1.0$（$10.0\text{ mm}$）**，文字垂直置中於 $-2.5\text{ mm}$。 |
| **9** | **主標題被內部垂直欄線切斷** | 垂直分割線起點設為外框頂線（$Y = 3494.25$），切過大標題。 | 內部垂直欄線起點嚴格設為 **$Y = 3484.25$（大標題底線）**，大標題保持純淨通欄。 |
| **10** | **停車表直欄線在第二類建築物遺失** | 誤將第三欄垂直分割線截斷在第二類建築物頂部。 | **第三欄（汽車）與第四欄（機車）之間的直欄線一律貫穿到底線（`ptBottomY`）**。 |

## 📊 6. 三大內嵌子表格原稿標準格式 (Statutory Sub-Tables)

所有子表格兩側外邊線相對於第二欄框線**各向內縮 $3.0\text{ mm}$**（子表格總寬 $214.0\text{ mm}$）。

### 6.1 表格 1：土地使用分區管制表（第二條（一））
* 欄寬配置：`[項目 52.0mm, 建蔽率 24.0mm, 容積率 24.0mm, 備註 114.0mm]`。
* 備註欄折行權重：**`25.5` 字寬**（留 $3\text{ mm}$ 安全邊距）。

### 6.2 表格 2：公共設施用地管制表（第二條（二）原稿合併儲存格）
* 欄寬配置：`[項目 52.0mm, 建蔽率 24.0mm, 容積率 24.0mm, 備註 114.0mm]`。
* **學校用地**：左側「`學校用地`」跨 2 列（$W = 18\text{ mm}$），右側區分「`文中、文小用地`」與「`文高`」（$W = 34\text{ mm}$），內部繪製垂直分割線，水平線不切斷學校用地。
* **停車場用地**：左側「`停車場用地`」跨 3 列（$W = 18\text{ mm}$），右側區分「`平面`」、「`立體`」、「`潭-停4`」（$W = 34\text{ mm}$），內部繪製垂直分割線，水平線不切斷停車場用地。

### 6.3 表格 3：標準停車設置表（第五條（二）原稿合併儲存格）
* 欄寬配置：`[分區或用地 45.0mm, 總樓地板面積 50.0mm, 汽車 59.0mm, 機車 60.0mm]`（總寬 $214.0\text{ mm}$）。
* **雙層表頭模矩化（14.0mm）**：
  * Row 1 為分區或用地（合併）、總樓地板面積（合併）、停車設置標準（跨 3, 4 欄，高 7mm）。
  * Row 2 在停車設置標準下方細分【汽車】與【機車(或自行車)】（高 7mm）。
* **第一類建築物**：第一欄「`第一類建築物`」跨 4 列合併，橫線切分 2、3、4 欄。
* **第二類建築物**：
  * 第一欄「`第二類建築物`」跨 4 列合併。
  * 第四欄「`每戶設1輛為原則`」跨 4 列合併。
  * **第三欄與第四欄之直欄垂直分割線從表頭中間線一路貫穿到底線（`ptBottomY`）**。
