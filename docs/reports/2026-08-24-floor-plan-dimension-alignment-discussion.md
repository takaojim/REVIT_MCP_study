## 📌 一、問題起源與幾何成因診斷

### 1. 現象觀察
在 Revit 各平面視圖（如 `RFL`、`2FL`）進行柱間距標註時，發現：
* **尺寸線彼此之間的間距**：皆精準控制在 **$65\text{ cm} (650\text{ mm})$**。
* **氣泡圓圈到第 1 道尺寸線的距離**：出現四邊不均勻的落差（例如在 RFL 出現 `124.9` vs `208.9`，在 2FL 出現 `85.2`、`54.9`、`68.8`、`70.9`）。

### 2. 根本物理原因（Revit 2D 視圖機制）
1. **每個視圖的 2D 軸線端點各自獨立**：
   * 在 Revit 中，每個平面視圖的軸線氣泡 2D 端點（`DatumExtentType.ViewSpecific`）都是獨立由繪圖員手動拉扯或裁切的。
   * 用單一樓層手動量測的固定常數套用到其他樓層，必定會產生微幅落差。
2. **圖面標準化之前提**：
   * 標註不能只自適應浮動的軸線端點，必須**先進行軸線齊頭整列（Align Grids）**，再進行**標準階梯標註（Step Dimensioning）**。

## 📐 二、核心數學模型：8 個「6.5mm 模矩 ($U$)」全區放樣

出圖比例 $S$（1:100 時 $S=100$），定義基準模矩單位：
$$U = 6.5\text{ mm} \times S \quad (\text{1:100 時 } U = 650\text{ mm} = 65\text{ cm})$$

### 1. 總間距階梯算式（柱間距 2 層 + 牆心 3 列）
$$\text{總間距} = 1 + 2 + 1 + 3 + 1 = \mathbf{8\text{ 個模矩}} = 8 \times 65\text{ mm} = \mathbf{52.0\text{ mm}}\ (\text{模型空間 } \mathbf{5,200\text{ mm}})$$

### 2. 8 階層級結構剖面圖

```
========================= 軸線氣泡圓圈中心 (端點基準線 Datum 0) =========================
   │
   ▼  [1U = 650mm] 氣泡與第一道線之留白間距
------------------------- 【第 1 道】全區總尺寸 (Total Dimension: 1440 / 1590) ---------
   │
   ▼  [1U = 650mm] 柱間距分段間距
------------------------- 【第 2 道】柱間距連續分段 (Column Spacing: 480 / 530) --------
   │
   ▼  [1U = 650mm] ★ 柱間距與牆心之間的空行緩衝隔離帶 (避免數字重疊混淆)
------------------------- -------------------------------------------------------------
   │
   ▼  [1U = 650mm] 進入牆心標註層
------------------------- 【第 3 道】外牆主要房間跨度尺寸 -------------------------------
   │
   ▼  [1U = 650mm]
------------------------- 【第 4 道】外牆門窗開口與柱體尺寸 -----------------------------
   │
   ▼  [1U = 650mm]
------------------------- 【第 5 道】陽台、雨遮、退縮細部開口尺寸 -----------------------
   │
   ▼  [1U = 650mm] 最末牆心標註線與最外牆實體之緩衝間距
┌────────────────────────────────────────────────────────────────────────┐
│               建物最外緣實體線 (外牆面 / 陽台外緣 / 雨遮外緣)            │
└────────────────────────────────────────────────────────────────────────┘
```

## 🛠️ 三、二階段標準技能拆分架構

為了避免一次交付兩項複雜幾何任務造成混淆，將工作流嚴格拆解為獨立二階段：

```mermaid
graph TD
    A["階段 1：軸線齊頭整列 (plan-grid-alignment)"] -->|輸出：四向齊頭軸線與精確氣泡坐標| B["階段 2：標準階梯標註 (plan-step-dimension)"]
    
    subgraph 技能 1：軸線四向齊頭整列
    A1["讀取當前視圖實體最大包絡 (外牆/陽台/雨遮)"] --> A2["計算四邊氣泡齊頭線 = 最外緣 + 8U (5200mm)"]
    A2 --> A3["調用 align_plan_grids 統一調整 2D Curve 與氣泡開關"]
    end
    
    subgraph 技能 2：標準平面分層階梯標註 (配置 A)
    B1["以齊頭氣泡為基準線"] --> B2["距氣泡 1U (65cm) 建立第 1 道全區總尺寸"]
    B2 --> B3["距第 1 道 1U (65cm) 建立第 2 道柱間距連續標註"]
    B3 --> B4["套用專屬標註型式 (北東上右、南西下右)"]
    end
```
